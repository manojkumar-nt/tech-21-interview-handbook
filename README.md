Welcome to the official public sampler for the **Tech-21 Series** — a modern, zero-fluff engineering interview guide and conceptual refresher built for software engineers, platform architects, and engineering leaders.

This public repository provides **Questions 01 through 03 + Preface** for all **13 technology editions**, complete with interactive architectural diagrams rendered natively via Mermaid, internal runtime mechanics, and structured pitfall tables.

--- 

## 💡 The Tech-21 Philosophy: Zero Fluff, Mental Models First

Most technical books waste the first 80 pages explaining trivial history ("Since the dawn of computing...", "In today's fast-paced world..."). Tech-21 jumps straight into architectural depth:

- 🧠 **Mental Model First**: We focus on runtime engines (V8, JVM, CPython, Node libuv), memory layouts (stack vs. heap allocation, pointer semantics), concurrency models, and OS kernel boundaries (Linux cgroups, namespaces).
- 📊 **Native Vector Diagrams**: Every single question includes architectural diagrams (`graph LR`) visualizing data structures and system pipelines.
- ⚠️ **Interview Traps & Pitfalls**: Structured comparison tables breaking down common myths vs. real internal behavior.
- ⚓ **60-Second Memory Anchor**: A punchy 1–2 sentence retention anchor designed to stick permanently.

## 📦 Curated Track Bundles (Full Editions)

Looking for the full editions with all 21 questions + reference appendices? The series is organized into 4 cohesive engineering tracks:

### 1. Modern Frontend & Fullstack Suite
> JavaScript • TypeScript • React • Node.js • Angular  
Master the browser execution loop, V8 engine internals, the React Fiber reconciler, Node libuv thread pool, and Angular signals reactivity.

### 2. Cloud-Native, DevOps & Platform Engineering Suite
> Docker • Kubernetes • Helm • Red Hat OpenShift  
Dive deep into Linux namespaces, cgroups v2, CRI-O, etcd distributed consensus, Operator Lifecycle Manager (OLM), and declarative GitOps.

### 3. Enterprise Architecture & Systems Design Suite
> System Design • Software Architect Technologies  
Master back-of-the-envelope calculations, distributed consensus (Raft/Paxos), event-driven Kafka architectures, CAP theorem tradeoffs, and caching patterns.

### 4. Backend & Systems Programming Suite
> Java (JVM Internals) • Python (CPython Internals)  
Understand JVM generational garbage collection (ZGC/G1), JIT compiler tiered compilation (C1/C2), CPython GIL mechanics, and object memory allocations.
